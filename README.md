# Birthday Card — Adah 🎂

A mobile-friendly, shareable birthday card made for GitHub Pages.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload **all files and folders inside this ZIP**.
3. Open **Settings → Pages**.
4. Under "Build and deployment", choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After GitHub finishes deploying, open the Pages URL and share it.

## Files

- `index.html` — the card
- `style.css` — mobile-first design
- `script.js` — screen transitions + confetti
- `assets/adah.jpg` — original card photo
- `assets/adah-friends.jpg` — newly added friends photo
- `assets/adah-corn.jpg` — newly added corn photo

No build step is required.
